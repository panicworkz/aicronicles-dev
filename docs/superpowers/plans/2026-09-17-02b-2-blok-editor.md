# ②b-2 Blok Düzenleme Çekirdeği — Uygulama Planı

> **Agentic worker'lar için:** GEREKLİ ALT-SKILL: superpowers:subagent-driven-development
> (önerilen) veya superpowers:executing-plans. Adımlar checkbox (`- [ ]`).

**Goal:** fabelo'nun blok düzenleme çekirdeğini (blok tanımları + satır-içi metin +
seçim/araç çubuğu/sürükle/geri-al yüzeyi) panic-cms'e birebir taşımak; ②a'daki
`blok-yuzeyi` STUB'ının yerine gerçeğini koymak.

**Architecture:** Editör tamamen client. `CanlıÖnizleme` (②a) bir `govde`
HTMLElement'ini ref ile tutar; useEffect'te `blokYuzeyiKur({govde,...})` çağırır.
Yüzey contentEditable uygular, seçim/araç çubuğu/sürükle olaylarını kurar, satır-içi
biçimlendirmeyi `blok-metin` ile bağlar. DOM davranışı yalnızca useEffect'te; render'da
`document`/`window` YOK (②b-2 spike'ında kanıtlandı).

**Tech Stack:** Next.js 15.5.25, React 19, TS, Vitest (+jsdom, yeni), contentEditable/execCommand.

**Spec:** [docs/superpowers/specs/2026-09-17-02b-2-blok-editor-design.md](../specs/2026-09-17-02b-2-blok-editor-design.md)
**Kaynak referans (SALT-OKUNUR):** fabelo `aicronicles-dev/src/lib/blok-turleri.ts`,
`aicronicles-dev/src/components/magazine/blok-metin.ts`, `.../blok-yuzeyi.ts`.

```ts
// @vitest-environment jsdom
import { describe, it, expect } from "vitest";
import { yapistirmayiTemizle } from "./blok-metin";

describe("yapistirmayiTemizle", () => {
  it("script'i içeriğiyle siler", () => {
    const out = yapistirmayiTemizle('<p>Metin</p><script>alert(1)</script>');
    expect(out).not.toMatch(/script/i);
    expect(out).toContain("Metin");
  });
  it("anlamsız span'ı açar, satır içi stili söker", () => {
    const out = yapistirmayiTemizle('<p>Merhaba <span style="color:red">dünya</span></p>');
    expect(out).not.toMatch(/span/i);
    expect(out).not.toMatch(/style=/i);
    expect(out).toContain("Merhaba");
    expect(out).toContain("dünya");
  });
  it("bağlantıya rel=noopener ekler", () => {
    const out = yapistirmayiTemizle('<a href="https://x.com">bağ</a>');
    expect(out).toMatch(/rel="noopener noreferrer"/);
  });
  it("boş inline kabuğu siler", () => {
    const out = yapistirmayiTemizle("<b></b>Metin");
    expect(out).not.toMatch(/<b><\/b>/);
    expect(out).toContain("Metin");
  });
});
```

  gorselAc: ()=>{}, urunAc: ()=>{}, gecmisDegisti: (g,i)=>setGecmis(`${g}/${i}`)})`.
  Ekranda: geri/ileri düğmeleri (yüzeyin `geriAl`/`ileriAl`), canlı "kaydedilecek HTML".
  Sayfa `/panic/blok-spike` (oturumZorunlu ÇAĞIRMA — layout oturumsuz çıplak render eder).
- [ ] **Step 2:** `PORT=3987 npm run dev` (arka planda). Built-in browser ile
  `http://localhost:3987/panic/blok-spike` aç. Konsolu oku: hydration hatası OLMAMALI.
- [ ] **Step 3: Kanıt senaryoları** (built-in browser: tıklama + gerekli yerlerde
  `javascript_tool` ile seçim/olay; her birinin sonucunu KANIT dokümanına yaz):
  - Boş/örnek gövdede "/" yaz → blok menüsü açılır (metinYuzeyiKur egik-çizgi).

    kaydedilen HTML'de mso-/style/boş span YOK (yapistirmayiTemizle + blogunIciniTemizle).
  - Kaydedilen HTML `htmlBloklara` (②a) ile bloklara dönüşebilir (harness'te göster/console).
